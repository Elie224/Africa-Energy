# Africa Energy SAU — Site Web

Site institutionnel d'Africa Energy SAU (Distribution petroliere, Guinee).

## Stack technique

- **React 18** + **Vite 5** (build tool moderne et rapide)
- **Bootstrap 5** + **Bootstrap Icons** (design responsive)
- **React Router 6** (navigation SPA)

## Demarrage

```bash
npm install
npm run dev
```

Le site sera accessible sur http://localhost:5173

## Charte graphique

- Bleu nuit #0B2A5B (fiabilite)
- Bleu accent #1E5BB8 (modernite)
- Orange energie #F39200 (hydrocarbures)
- Vert continental #2E7D32 (Afrique)
- Or premium #D4A017
